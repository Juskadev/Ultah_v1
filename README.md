# 🌌 Cosmic Love — Romantic Birthday Website 3D & Hands-Free

> *"Di antara miliaran bintang di alam semesta, aku tetap memilih kamu."*

Website ulang tahun romantis premium berkelas cinematic bertema **"Cosmic Love / Love in the Universe"** dengan visual **3D WebGL (Three.js)**, **Mode Otomatis Tanpa Klik (Hands-Free Cinema Tour)**, dan **Admin Dashboard Lengkap** untuk mengubah foto, teks, surat cinta, dan lagu secara langsung dari browser!

---

## ✨ Fitur Baru yang Ditambahkan

### 1. 🎬 Mode Otomatis Tanpa Klik (Hands-Free Cinema Tour)
- **Layar Pembuka Otomatis:** Menghitung mundur (4 detik) dengan progress bar bercahaya dan langsung masuk secara otomatis ke galaksi tanpa harus diklik.
- **Cinematic Auto-Tour Controller:**
  - Website bergulir secara otomatis dengan pergerakan yang sangat halus dan sinematik.
  - Berhenti sejenak di bagian **Surat Cinta** agar pacar bisa membaca pesannya dengan nyaman.
  - Saat tiba di bagian **Kue Ulang Tahun**, lilin akan **ditiup secara otomatis** setelah hitungan mundur 3 detik, disusul letusan kembang api dan confetti supernova!
  - Setelah melewati penutup, **Pesan Rahasia Cinta** akan terbuka secara otomatis.
  - Dilengkapi kontrol floating elegan: **Play / Pause (⏯️)**, **Kecepatan Putar (0.5x, 1x, 1.5x)**, **Lompat ke Bagian Berikutnya (⏩)**, dan **Putar Ulang (🔄)**.
  - Jika pacar menyentuh atau menggulir layar secara manual, sistem mendeteksi secara halus dan memberikan tombol *"Resume Auto-Tour"*.

### 2. 🪐 Animasi 3D Kosmik (Three.js WebGL)
- **Matahari 3D Bercahaya:** Bola matahari di pusat galaksi dengan shader corona yang berdenyut (*pulsing*) dan memancarkan cahaya hangat ke seluruh ruang angkasa.
- **Orbit 3D & Foto Pasangan:** Foto-foto kenangan ditempatkan di atas piringan portal 3D bercahaya yang mengorbit matahari dalam ruang 3 dimensi dengan kemiringan sudut realistis.
- **Planet-planet 3D:** Planet Saturnus dengan cincin 3D ganda yang miring, kristal ungu, dan planet samudra bercahaya.
- **3.500+ Partikel Bintang & Awan Nebula 3D:** Taburan bintang dengan kedalaman ruang nyata serta awan nebula kosmik berwarna magenta, ungu, dan emas.
- **Meteor / Bintang Jatuh 3D:** Garis komet bercahaya melintasi kamera 3D secara acak.
- **Kamera Sinematik 3D:** Kamera bergerak dinamis merespons pergerakan kursor mouse/touch dan melakukan *dolly swoop* saat halaman digulir.

### 3. 🛠️ Admin Dashboard (Ubah Konten Langsung dari Browser)
- **Cara Akses Admin:**
  - Klik tombol melayang **"Admin Panel ⚙️"** di pojok kiri bawah layar, atau tekan tombol keyboard `Ctrl + Shift + A`.
  - Masukkan PIN keamanan Admin Anda.
- **Fitur Admin:**
  - 📝 **Nama & Judul:** Ubah nama pacar, nama kamu, judul hero, dan kalimat pembuka.
  - 💌 **Surat Cinta:** Tulis atau edit surat cinta panjang dengan format paragraf bebas.
  - 📸 **Kelola Foto (Upload Langsung!):**
    - Upload foto langsung dari file komputer atau HP.
    - Foto otomatis diubah ke data gambar lokal dan langsung tampil di orbit 3D serta galeri kenangan tanpa perlu server backend!
    - Ubah caption, tambah foto baru, atau hapus foto.
  - ⏳ **Timeline Cerita:** Tambah atau ubah momen perjalanan cinta (tanggal, judul, cerita, emoji, dan foto).
  - 🎂 **Kue & Harapan:** Kustomisasi ucapan lilin ditiup dan balasan doa.
  - 🎵 **Musik:** Upload file MP3 kesukaan atau masukkan link audio.
  - 💾 **Simpan & Cadangan:**
    - Tombol *"Simpan Semua Perubahan"* (langsung tersimpan di browser tanpa reload).
    - *"Download Backup (JSON)"* untuk menyimpan file cadangan.
    - *"Impor Backup (JSON)"* untuk memulihkan pengaturan.
    - *"Reset ke Bawaan"* jika ingin kembali ke data awal.

## 🚀 Menjalankan Website Secara Lokal

1. Buka terminal di folder project:
   ```bash
   npm run dev
   ```
2. Buka browser di:
   ```
   http://localhost:5173/
   ```

3. Untuk kompilasi produksi:
   ```bash
   npm run build
   ```
